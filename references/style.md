# 画风与文案风格

这套画风经过成片验证、用户认可。数值已经写进 templates（index.html 的 CSS 变量、core.js 的 V 常量）；本文讲每个数值管什么、为什么这样定、换主题时哪些能动。

一句话：暗色暖调底，金银两色的线稿和大字；精致，整屏都是画布，但每个元素都有用；字幕讲故事，画面演字幕，动作踩在小节和拍点上。

## 精致

精致是风格：画面可以丰富，整屏都是画布，不要小气。但不为复杂而复杂——每个元素都要有用、和当前字幕相关；无用或相关性低的东西不加。

- 丰富度从这几处来：层次（远中近景）、结构密度（线框、排线）、同一意象的变奏与呼应、辅助细节（刻度、标注、微光）。
- 空间组织是设计出来的：疏密、重心、和字幕的呼应都要“被安排在画面里”。可以密，不能乱。
- 完成度是底线：位置、线宽、透明度、时机都经得起定格细看；发光有亮起和暗下两段层次，金变银恰好踩在语义的转折点上，开头埋下的意象在结尾回来补全。
- 验收标准：随便定格一帧，截出来能当一张海报。达不到就继续调——但不许加无关的东西遮丑。

## 色板

| 名字 | 值 | CSS / JS | 用在哪 |
|---|---|---|---|
| ink | `#efe9df` | `--ink` / `INK` | 正文、字幕、中性线稿 |
| 金 | `#f2c46d` | `--gold` / `GOLD` | 主角、正面、关键词、题眼 |
| 银 | `#c8ced8` | `--silver` / `SILVER` | 反面、对照、“转过去之后” |
| muted | `#a39887` | `--muted` / `MUTED` | 标签、出处、次要说明 |
| 暗 | `#7a6c58` | `--dim` / `DIM` | 枯萎、退场、退到背景的字 |
| 红 | `#e8794a` | `--red` / `RED` | 警示。全片最多一处，比如蓄压到极限爆发的那一拍 |
| 背景 | `#221b12 → #15110b → #0c0a07` | `#root` 的径向渐变 | 不改 |

- 金只给主角和关键词：画面里的金色主角和字幕里的金色关键词说的是同一件事。两栏对照时左右各有一个。
- 金变银表示转向反面（“反”走到对面、光点越过顶点、钟摆摆到另一头），银变回金表示回来。颜色的变化本身就在讲内容。
- ink 线稿靠透明度分层：参考圆、中线这类背景结构 0.16–0.22，地平线等次要线 0.35–0.4，要看清的线 0.55–0.6；栏目名 0.5，小标题 0.85。点亮后的圆描边用金色 0.45。
- 填充只给本来就是“面”的东西：水、光束、影子、被照亮的人形、太极的暗半边、圆牌底。辅助暗色只用低饱和的灰和褐（`#55585e`、`#34363b`、圆牌底的暗褐渐变），不引入新的彩色。
- 渐变除了背景和圆牌底的暗褐，只做两件事：金到银的弧（转向反面），以及光束、水波、光晕从实到虚的透明度渐隐。

## 字体与字号

题眼、原文、大字用 Noto Serif SC；字幕、问题、标签、说明用 Noto Sans SC。字重 700–800，不用 900。大字的字距 6–12px，正文 2–4px。

| 元素 | 字体 | 字号 / 字重 / 颜色 | top |
|---|---|---|---|
| 题眼 `#hook` | Serif | 140 / 800 / 金，字距 12 | 330 |
| 逐字大字 `.ch`（逐字亮、沿圆走） | Serif | 168 / 800 / 金；第二行 `.l2` 缩到 0.714 | 320 / 470 |
| 开头问题 `#q` | Sans | 52 / 700；关键词金色，第 2 拍画出下划线 | 586 |
| 人名、术语、圆牌上的字（`#jName` `#enW` `.face`） | Serif | 120–150 / 700–800 / 金；圆牌的“祸”面用银 | 330–360 |
| 原文大字、两栏标题、结尾大字（`.big` `.colh` `.lab` `#eTxt`） | Serif | 44–66 / 700，金或 ink | 视画面 |
| 原文引句 `.quote` | Serif | 40；`<b>` 金、`<em>` 银，都是 700 | 视画面 |
| 小标题 `.head` | Sans | 32 / ink 0.85，字距 6；下方一条 72×2 的金线 | 118 |
| 字幕 `.cap` | Sans | 48 / 700，字距 2；`<b>` 金 | 896 |
| 标签、说明（`.lbl` `.lbl2` `.who` `.note`，人名、术语下的副标题） | Sans | 24–30 / muted，字距 3–6 | 视画面 |

## 版面

| 区域 | 位置（px） | 放什么 |
|---|---|---|
| 角标 | top 44，左右各留 56 | 左：栏目名（如「领域 × 主题」）；右：出处 |
| 小标题 | top 118 | 分段标题，如“相同点 ① · 对立相依”“不同点 ② · 应对”，可省 |
| 主画面 | 约 200–800；圆心常用 (960, 450)，半径 210 | 主意象 + 辅助细节；580 以下常放问题、原文或一行说明 |
| 字幕 | top 896 | 只放字幕 |

- 字幕区（约 860 以下）不放图形，图形也不伸进去。
- 两栏对照：左栏 left 140、右栏 left 1260，各宽 520，中间留给中线。
- 出处写书名加章节，如 `《书名》第五章`；两栏各有出处时用全角竖线隔开：`《书名》第二章 ｜ 某人《著作名》`；生活化的例子标 `生活举例，非某某原话`。
- 画面可以铺满，但每个元素都要有用；不为填满而填满。

## 线稿

- 线宽：辅助线 2，主线和弧线 3，人形 4，粗线（植物茎、脸、爆发线、碎弧）5–6。弧、茎、人形、脸这类端点露在外面的线，端点和拐角用 round；辅助线、整圆、两端被圆点盖住的线（钟摆杆）不用加。
- 每个场景一张全幅 SVG `<svg width="1920" height="1080" viewBox="0 0 1920 1080">`，坐标就是画面像素。
- 简笔人形：r16 的头加四笔身体（躯干一竖、两臂一横、两腿两斜）；倒影用 `translate(0 1040) scale(1 -1)`，换成银色。
- 会被缩放的图形加 `vector-effect: non-scaling-stroke`，线宽不跟着变。
- 文字发光只用金色 text-shadow：拍点上亮到 `0 0 30px rgba(242,196,109,0.7)` 再暗下；要一直强调的字留一层弱光（26px、0.55）。

## 3D 线框（Three.js，具象主题优先、不硬用）

什么时候用 3D：主题有实体形态——建筑、桥梁、器物、机械、地形、生物结构。线框能把“结构”讲清楚，精致感来自密度和纵深（参照印象：金色线框主体浮在暗色空间里，相机缓推，辉光克制）。

什么时候不硬用：抽象概念（哲学、心理、关系）没有天然形态，硬建模反而假——继续用 2D 意象库那套。一期里可以混用：这一屏 3D 结构、下一屏 2D 意象；每个镜头聚焦一个主意象，配辅助细节。

画面规则：

- 色板和语义不变：主体线框金、对照银，金变银仍是“转向反面”；材质只设颜色，不做写实 PBR、不贴图。
- 网格地面暖色、稀疏、低透明（≈0.14），只起参照；远处用雾淡进背景色，拉纵深。
- 辉光克制：UnrealBloomPass threshold≈0.6、strength≈0.5、radius≈0.4，只让亮线微微发光，不满屏泛光。
- 相机慢：一次运动 ≥ 2 小节，推近、环绕为主，ease none 或 sine.inOut；不猛转、不晃。
- 文字一律 DOM 层（年份、标注、字幕），不画进 WebGL——字体子集和对比度检查只管 DOM。
- 首帧可读、聚焦一个主意象、字幕区不进图形：这些原则对 3D 同样成立。

3D 特有的 avoid：写实 PBR 材质和贴图、冷色霓虹网格（我们的网格是暖色低透明参照）、相机猛转猛甩、满屏粒子、线框密度高到糊成色块。

## 动效节奏

- 一小节一个镜头、一条字幕：场景切换和字幕换条都在小节重拍上。小节内的强调（亮一下、弹出、画下划线）放在拍点上，`at(bar, 1)`、`at(bar, 2)` 最常用；几个元素依次出现时错开 1/4–1 拍。
- 动作要演出字幕的意思：说“转向反面”，东西就走到对面变银；说“回到原点”，就走回来变金。和字幕无关的动作不加。
- 最关键的一句放在配乐高潮起点的重拍上（配乐从安静进入饱满的那一拍）。
- 背景一直在动但很轻：光带每小节脉动一次，镜头整段推近 3%。core.js 已写好，不另加。
- 结尾留一两小节无字幕的定格，渐黑和配乐淡出同步。
- ease 以 power2.out 为主；往返用 power2.inOut 或 sine.inOut；位移加缩放、翻转、转半圈这类大动作用 power3.inOut；弹出用 back.out(1.6–3)。examples 没用过 elastic、bounce，保持克制。

| 动作 | 数值（取自 examples） |
|---|---|
| 入场 | 0.35–0.45 秒 power2.out，y 12 → 0（`fadeIn`） |
| 弹出 | 0.25–0.35 秒 back.out(2–3)，scale 0 → 1 |
| 亮一下 | 0.08–0.12 秒亮到发光，再用 0.4–0.6 秒暗下 |
| 脉冲环 | r 加 50–70，opacity 0.7–0.8 → 0，0.7–0.9 秒 power2.out |
| 翻牌 | scaleX 1 → 0（0.14 秒 power2.in），压扁时换字，再 0 → 1（0.24 秒 power2.out） |
| 描线 | strokeDashoffset 从全长到 0，0.6–0.9 秒或 2 拍，power2.inOut 或 power2.out |
| 摇摆 | 每拍 ±5°，sine.inOut |
| 枯萎、变形 | `attr:{d}` 变形，同时 GOLD → DIM，0.6 秒 power2.inOut |
| 匀速转动、流动 | ease none，时长按小节差算，如 `at(22) - at(19)` |

代码怎么写，按 hyperframes.md 的动画模式索引查 examples。

## 字幕文案

教程原话：“文章是给人读的，视频是给人刷的，所以一定要简单易懂，观众才愿意看下去。”

- 长度：一小节一条。不计标点一般不超过 12 字，最多 13 字，算上标点不超过 16 个字符；再长就拆成两条，或者占两小节。6–9 字的短句可以用。112.9 BPM 时一小节 2.13 秒，12 字约每秒 5.6 字；配乐更快就相应减字。实测：6–12 字最稳，超过 13 字就显挤。
- 金色：每条一处 `<b>`，放在这条最该记住的词上。对举句可以两处，全片一两条（“草木活着时**柔软**，死了才**僵硬**”）；纯过渡句可以不加（“回到开头的问题”）。
- 语气：口语短句，像当面讲给一个人听。用“先看”“可”“所以”“下次……的时候”串起来；不用感叹号；删掉“众所周知”“让我们一起来看看”这类套话。
- 引用写明是谁说的：“某某说：……”“某某提醒你：……”。
- 每条都要有信息量：删掉不影响意思的字；整条删掉也不影响的，就删整条。

语气套路（加粗即金色）：抛答案——“答案，就这**四个字**”；破误解——“可这句话，原典里**没有**”；下定义——“弱，**不是没力气**”；打比方——“就像一直压着脾气的**老好人**”；收尾落地——“下次想硬撑的时候，**想想水**”。

叙事弧模板（段落顺序不变；小节数按配乐和 1 分钟上限收成，下表小节号只是参考比例）：

| 小节 | 段落 | 做什么 |
|---|---|---|
| 0 | 钩子 | 题眼大字加一个反常识的问题，第一帧就能读 |
| 1 | 抛出答案 | 一句话抛出，如“答案，就这四个字” |
| 2–5 | 拆字 | 一层意思一个画面 |
| 6–7 | 破误解 | 常见说法 → 原典里没有 |
| 8–16 | 原典 | 从配乐高潮起点开始，一句原文一个意象 |
| 17–25 | 第二个点 | 同样的节奏讲第二句 |
| 26–29 | 回到问题 | 用前面讲的回答开头的问题 |
| 30–34 | 落地 | 原文金句，再加一句能带走的话 |
| 35–36 | 定格 | 无字幕，题眼回来，渐黑 |

## avoid

教程原话：“记住一定要这里要写avoid，不写它很容易给你那些深色背景，紫色霓虹那种AI风格”。我们的底也是深色，区别在于暖调（褐、琥珀）、低饱和、只有金银两色，没有冷色发光。

写生图提示词、和用户讨论配色、看截图自查时，都过一遍：

- 深色配紫色或蓝色霓虹、赛博网格、满屏发光粒子、渐变描边按钮；
- 被否过的：字装进硬币或卡片，竹简、方块当底板，满屏浮尘，注释小字堆叠，900 字重；
- 照片、插画（前两期都没用；真要配图先问用户，并注明出处）；音效、配音；
- 无用或相关性低的元素（不为复杂而复杂）；和字幕无关的动作；字幕区里的图形。
- 3D 场景另有一组 avoid（写实材质、冷色霓虹网格、相机猛甩、满屏粒子），见「3D 线框」一节。

## 换主题时

- 不变：背景、色板语义、字号层级、版面分区、字幕规则、动效节奏。
- 先定维度：具象实体主题默认优先 3D 线框，抽象概念默认 2D；优先但不硬用，一期里可混用，按小节算。
- 要换：栏目名、题眼和问题、意象、小标题。
- 用户想要新画风时，按教程先出三个样式（各做一张 snapshot 拼图或一段 10 秒样片）给用户挑，每个都写明 avoid；选定后把数值改进 templates，并更新本文。

## 自查（snapshot 之后，和 verify.md 的看图清单一起过）

- 第一帧能读出题眼和问题；
- 元素可以丰富，但每个都有用、和当前字幕相关；没有装饰性的容器；金色只在主角和关键词上，红色全片不超过一处；
- 随便定格一帧都经得起细看（精致：对齐、端点、间距、透明度分层都到位，能当一张海报）；
- 没有色板外的彩色，没有 900 字重，没有感叹号；
- 字幕区没有图形；每个动作都在演当前这条字幕，并且落在重拍或拍点上；
- 下面三条命令在 `<主题目录>` 下跑，列出来的每一项都确认是有意的：
