# 画风与文案风格（v2）

第一期完整版和第二期分片文案都按这一套做，用户认可。数值已经写进 templates（index.html 的 CSS 变量、core.js 的 V 常量）；本文讲每个数值管什么、为什么这样定、换主题时哪些能动。

一句话：暗色暖调底，金银两色的线稿和大字，一屏一个意象；字幕讲故事，画面演字幕，动作踩在小节和拍点上。

## 从 v1 到 v2

v1 样片被否，用户原话：“图像设计的有些不好看, 更简洁一点”（同时要求不配音、背景音用参考视频原音轨）。改成 v2 后通过：“可以. 做完整版吧”。

| v1（被否） | v2（通过） |
|---|---|
| 金币、银币造型，字装进硬币 | 字用素色直接放，不装进任何容器 |
| 竹简、方块卡片当底板 | 只用圆、线、点、简笔人形 |
| 满屏漂浮的光粒（浮尘） | 去掉；背景只留暖光带和下半部极淡的横纹 |
| 注释小字多 | 右上角一行出处 |
| 标题字重 900 | 700–800 |
| Kokoro 男声配音 | 无配音，只有字幕 |

边界：图形本身在演这条字幕时可以画，比如祸福圆牌（s1_lao.js:66-78）、写着“返也者道动也”的郭店竹简（第二期第 12 小节）、让金线穿过缝隙的银色方块（第二期第 23–24 小节）。条件是单线、单色、一屏一个，不当底板或装饰。

画面上的大字只用原典原文和字幕里的词。不是原典的说法不当原文上屏（“滴水穿石”就没上屏）；要辟谬时可以出现，但要当场划掉或标明出处（第二期第 6–7 小节的“物极必反”）。

## 极简与精致

极简是风格，精致是底线。一屏一个意象是取舍，不是省事：元素越少，每一笔越被看得清楚——位置、线宽、透明度、时机，任何一处不到位都无处藏身。

- 留白是设计出来的，不是画完剩下的空地：主体的重心、平衡、和字幕的呼应，都要“被安排在画面里”。
- 精致感靠完成度堆出来：发光有亮起和暗下两段层次，金变银恰好踩在语义的转折点上，开头埋下的意象在结尾回来补全。
- 验收标准：随便定格一帧，截出来能当一张海报。达不到就继续收、继续调——不许加东西遮丑。

- 金只给主角和关键词：画面里的金色主角和字幕里的金色关键词说的是同一件事。两栏对照时左右各有一个。

- ink 线稿靠透明度分层：参考圆、中线这类背景结构 0.16–0.22，地平线等次要线 0.35–0.4，要看清的线 0.55–0.6；栏目名 0.5，小标题 0.85。点亮后的圆描边用金色 0.45。
- 填充只给本来就是“面”的东西：水、光束、影子、被照亮的人形、太极的暗半边、圆牌底。辅助暗色只用低饱和的灰和褐（`#55585e`、`#34363b`、圆牌底的暗褐渐变），不引入新的彩色。
- 渐变除了背景和圆牌底的暗褐，只做两件事：金到银的弧（转向反面），以及光束、水波、光晕从实到虚的透明度渐隐。

## 线稿

- 线宽：辅助线 2，主线和弧线 3，人形 4，粗线（植物茎、脸、爆发线、碎弧）5–6。弧、茎、人形、脸这类端点露在外面的线，端点和拐角用 round；辅助线、整圆、两端被圆点盖住的线（钟摆杆）不用加。
- 每个场景一张全幅 SVG `<svg width="1920" height="1080" viewBox="0 0 1920 1080">`，坐标就是画面像素。
- 简笔人形：r16 的头加四笔身体（s2_jung.js:45-47）；倒影用 `translate(0 1040) scale(1 -1)`，换成银色。
- 会被缩放的图形加 `vector-effect: non-scaling-stroke`，线宽不跟着变。
- 文字发光只用金色 text-shadow：拍点上亮到 `0 0 30px rgba(242,196,109,0.7)` 再暗下；要一直强调的字留一层弱光（26px、0.55，s0_open.js:98-101）。

## 3D 线框（Three.js，具象主题优先、不硬用）

什么时候用 3D：主题有实体形态——建筑、桥梁、器物、机械、地形、生物结构。线框能把“结构”讲清楚，精致感来自密度和纵深（参照：vibe知识大赏的广济桥，金色线框桥体 + 相机缓推 + 克制的辉光）。

什么时候不硬用：抽象概念（哲学、心理、关系）没有天然形态，硬建模反而假——继续用 2D 意象库那套。一期里可以混用：这一屏 3D 结构、下一屏 2D 意象，一屏一个意象的原则不变。

画面规则：

- 色板和语义不变：主体线框金、对照银，金变银仍是“转向反面”；材质只设颜色，不做写实 PBR、不贴图。
- 网格地面暖色、稀疏、低透明（≈0.14），只起参照；远处用雾淡进背景色，拉纵深。
- 辉光克制：UnrealBloomPass threshold≈0.6、strength≈0.5、radius≈0.4，只让亮线微微发光，不满屏泛光。
- 相机慢：一次运动 ≥ 2 小节，推近、环绕为主，ease none 或 sine.inOut；不猛转、不晃。
- 文字一律 DOM 层（年份、标注、字幕），不画进 WebGL——字体子集和对比度检查只管 DOM。
- 首帧可读、一屏一个意象、字幕区不进图形：这些原则对 3D 同样成立。

3D 特有的 avoid：写实 PBR 材质和贴图、冷色霓虹网格（我们的网格是暖色低透明参照）、相机猛转猛甩、满屏粒子、线框密度高到糊成色块。

## 动效节奏

- 一小节一个镜头、一条字幕：场景切换和字幕换条都在小节重拍上。小节内的强调（亮一下、弹出、画下划线）放在拍点上，`at(bar, 1)`、`at(bar, 2)` 最常用；几个元素依次出现时错开 1/4–1 拍。
- 动作要演出字幕的意思：说“转向反面”，东西就走到对面变银；说“回到原点”，就走回来变金。和字幕无关的动作不加。
- 最关键的一句放在配乐高潮起点的重拍上（两期都是第 8 小节：第一期祸福翻牌，第二期“物壮则老”）。
- 背景一直在动但很轻：光带每小节脉动一次，镜头整段推近 3%。core.js 已写好，不另加。
- 结尾留一两小节无字幕的定格，渐黑和配乐淡出同步。
- ease 以 power2.out 为主；往返用 power2.inOut 或 sine.inOut；位移加缩放、翻转、转半圈这类大动作用 power3.inOut；弹出用 back.out(1.6–3)。examples 没用过 elastic、bounce，保持克制。

| 动作 | 数值（取自 examples） |
|---|---|
| 入场 | 0.35–0.45 秒 power2.out，y 12 → 0（`fadeIn`） |
| 弹出 | 0.25–0.35 秒 back.out(2–3)，scale 0 → 1 |
| 亮一下 | 0.08–0.12 秒亮到发光，再用 0.4–0.6 秒暗下 |
| 脉冲环 | r 加 50–70，opacity 0.7–0.8 → 0，0.7–0.9 秒 power2.out |
| 翻牌 | scaleX 1 → 0（0.14 秒 power2.in），压扁时换字，再 0 → 1（0.24 秒 power2.out） |
| 描线 | strokeDashoffset 从全长到 0，0.6–0.9 秒或 2 拍，power2.inOut 或 power2.out |
| 摇摆 | 每拍 ±5°，sine.inOut |
| 枯萎、变形 | `attr:{d}` 变形，同时 GOLD → DIM，0.6 秒 power2.inOut |
| 匀速转动、流动 | ease none，时长按小节差算，如 `at(22) - at(19)` |

代码怎么写，按 hyperframes.md 的动画模式索引查 examples。

## 字幕文案

教程原话：“文章是给人读的，视频是给人刷的，所以一定要简单易懂，观众才愿意看下去。”

- 长度：一小节一条。不计标点一般不超过 12 字，最多 13 字，算上标点不超过 16 个字符；再长就拆成两条，或者占两小节。6–9 字的短句可以用。112.9 BPM 时一小节 2.13 秒，12 字约每秒 5.6 字；配乐更快就相应减字。两期实测：第二期 34 条 6–12 字；第一期 38 条 6–14 字，14 字的只有“荣格提醒你：看见被你推开的自己”，偏长。
- 金色：每条一处 `<b>`，放在这条最该记住的词上。对举句可以两处，全片一两条（“草木活着时**柔软**，死了才**僵硬**”）；纯过渡句可以不加（“回到开头的问题”）。
- 语气：口语短句，像当面讲给一个人听。用“先看”“可”“所以”“下次……的时候”串起来；不用感叹号；删掉“众所周知”“让我们一起来看看”这类套话。
- 引用写明是谁说的：“老子说：……”“钱锺书说：……”“荣格提醒你：……”。
- 每条都要有信息量：删掉不影响意思的字；整条删掉也不影响的，就删整条。

已通过的例句（加粗即金色）：“老子的回答，就这**十个字**”“可这四个字，《道德经》里**没有**”“弱，**不是没力气**”“就像一直压着脾气的**老好人**”“某天，突然**爆发**”“下次想硬撑的时候，**想想水**”。

## avoid

教程原话：“记住一定要这里要写avoid，不写它很容易给你那些深色背景，紫色霓虹那种AI风格”。我们的底也是深色，区别在于暖调（褐、琥珀）、低饱和、只有金银两色，没有冷色发光。

写生图提示词、和用户讨论配色、看截图自查时，都过一遍：

- 深色配紫色或蓝色霓虹、赛博网格、满屏发光粒子、渐变描边按钮；
- v1 被否的：字装进硬币或卡片，竹简、方块当底板，满屏浮尘，注释小字堆叠，900 字重；
- 照片、插画（前两期都没用；真要配图先问用户，并注明出处）；音效、配音；
- 一屏两个以上主意象；和字幕无关的动作；字幕区里的图形。
- 3D 场景另有一组 avoid（写实材质、冷色霓虹网格、相机猛甩、满屏粒子），见「3D 线框」一节。

## 换主题时

- 不变：背景、色板语义、字号层级、版面分区、字幕规则、动效节奏。
- 先定维度：具象实体主题默认优先 3D 线框，抽象概念默认 2D；优先但不硬用，一期里可混用，按小节算。
- 要换：栏目名、题眼和问题、意象、小标题。
- 用户想要新画风时，按教程先出三个样式（各做一张 snapshot 拼图或一段 10 秒样片）给用户挑，每个都写明 avoid；选定后把数值改进 templates，并更新本文。

## 自查（snapshot 之后，和 verify.md 的看图清单一起过）

- 第一帧能读出题眼和问题；
- 每屏一个主意象，没有装饰性的容器；金色只在主角和关键词上，红色全片不超过一处；
- 随便定格一帧都经得起细看（极简但精致：对齐、端点、间距、透明度分层都到位，能当一张海报）；
- 没有色板外的彩色，没有 900 字重，没有感叹号；
- 字幕区没有图形；每个动作都在演当前这条字幕，并且落在重拍或拍点上；
- 下面三条命令在 `<主题目录>` 下跑，列出来的每一项都确认是有意的：

```bash
# 1. 色板以外的颜色：应该只剩低饱和的辅助暗色
grep -noE "#[0-9a-fA-F]{6}\b" full/*.js full/index.html | grep -viE "efe9df|f2c46d|c8ced8|a39887|7a6c58|e8794a|221b12|15110b|0c0a07" || echo 无
# 2. 900 字重、感叹号
grep -nE "font-weight: *900|fontWeight: *\"?900|！" full/*.js full/index.html || echo 无
# 3. 字幕：超过 12 字或 16 个字符、金色不是一处、带感叹号的（对举句、过渡句属于有意）
"$PY" -c 'import re, sys
P = "，。：；？！、“”‘’《》（）·—…「」 ,.:;?!"
for bar, t in re.findall(r"\[\s*(\d+),\s*\"([^\"]*)\"", open(sys.argv[1], encoding="utf-8").read()):
    s = re.sub(r"<[^>]+>", "", t); n = sum(c not in P for c in s)
    if n > 12 or len(s) > 16 or t.count("<b>") != 1 or "！" in s or "!" in s:
        print("第", bar, "小节：", n, "字", len(s), "字符", t.count("<b>"), "处金色 |", s)' full/captions.js
```
